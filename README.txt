Public Releases of Waters/Supremica IDE

This is an empty repository without source code.
It contained binary releases of Waters/Supremica IDE compiled from the official Supremica repository, while it was a private repository.
This is no longer needed as the official Supremica repository became public in 2025. Therefore this repository will not be maintained any longer.

Starting with the release of Waters/Supremica IDE 2.8, downloads are possible through the repository Chalmers-Control-Automation-Mechatronics/Supremica accesed via
https://github.com/Chalmers-Control-Automation-Mechatronics/Supremica
